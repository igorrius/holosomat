# 🎤 Голосомат

Програма для Windows, яка змінює голос у реальному часі — для ігор, Discord і просто щоб посміятись.
Написана на Rust.

Вміє:

- змінювати **висоту** голосу і **тембр** окремо (тому бас не звучить як сповільнена плівка, а писк — як бурундук, якщо ти цього не хочеш);
- режими **робот** і **шепіт**;
- ефекти: хрипіння, «метал», рація, 8-біт, луна, реверберація;
- **11 готових голосів**, серед них «Голос бати», «Велетень», «Робот», «Монстр з печери», «Привид»;
- **зберігати свої голоси** і завантажувати їх (це звичайні `.json` файли — ними можна обмінюватися з друзями).

## Як запустити

1. Завантаж `Holosomat-windows-x64` з розділу **Actions** (останній зелений запуск → Artifacts) або з **Releases**.
2. Встанови **[VB-Audio Virtual Cable](https://vb-audio.com/Cable/)** (безкоштовно, після встановлення перезавантаж комп). Це «віртуальний дріт»: Голосомат кладе в нього змінений голос, а гра бере його звідти як з мікрофона.
3. Запусти `Holosomat.exe`. Він сам знайде кабель.
   - **Мікрофон** — твій справжній мікрофон.
   - **Куди йде голос** — `CABLE Input`.
   - **Чути себе в** — навушники, якщо хочеш чути, як звучиш (краще саме навушники, а не колонки, інакше буде луна).
4. У Discord / грі в налаштуваннях голосу обери мікрофоном **`CABLE Output`**.
5. У Discord вимкни **шумозаглушення (Krisp)** і **ехоподавлення** — вони «з'їдають» ефекти, особливо робота.

Велика зелена кнопка зверху миттєво вмикає/вимикає ефект — щоб сказати щось своїм голосом.

## Свої голоси

Покрути повзунки → впиши назву внизу ліворуч → **💾 Зберегти**.
Кнопка **📂 Папка** відкриває папку з пресетами (`%APPDATA%\Holosomat\config\presets`).

Пресет — це простий текстовий файл. Можна писати лише ті поля, які змінюєш:

```json
{
  "name": "Мій монстр",
  "description": "Гарчить і хрипить",
  "pitch": -10.0,
  "formant": -6.0,
  "drive": 0.4,
  "reverb_mix": 0.3
}
```

| Поле | Що робить | Діапазон |
|---|---|---|
| `pitch` | висота голосу, півтони | -12 … 12 |
| `formant` | тембр («розмір горла»), півтони | -12 … 12 |
| `mode` | `"Normal"`, `"Robot"` або `"Whisper"` | |
| `drive` | хрипіння | 0 … 1 |
| `ring_mix`, `ring_freq` | «метал» і його частота (Гц) | 0 … 1, 20 … 1000 |
| `low_cut`, `high_cut` | зрізати низи / верхи (Гц) | 20 … 2000, 1000 … 20000 |
| `crush_bits`, `crush_rate` | 8-біт: кількість біт і «пікселізація» | 2 … 16, 1 … 32 |
| `echo_mix`, `echo_ms`, `echo_feedback` | луна | 0 … 1, 20 … 1000, 0 … 0.95 |
| `reverb_mix`, `reverb_size` | реверберація | 0 … 1 |
| `volume_db` | гучність, дБ | -20 … 20 |
| `gate_db` | глушити тишу (-80 = вимкнено) | -80 … -20 |

## Як це працює

```
мікрофон → гейт → висота і тембр → ефекти → гучність → CABLE Input → гра
```

- **Висота і тембр** (`src/dsp/pitch.rs`). Звук ріжеться на шматочки по ~20 мс, кожен через
  FFT перетворюється на спектр (які частоти звучать). Гармоніки голосу зсуваються вгору чи вниз —
  це висота. Окремо з спектра виділяється «огинаюча» (кепстр) — це тембр, його зсуваємо
  на своє значення. Потім усе збирається назад у звук. Алгоритм називається *phase vocoder*.
- **Робот** — у спектрі обнуляються фази, і голос стає монотонним дзижчанням.
  **Шепіт** — фази випадкові, і зникає висота тону.
- **Ефекти** (`src/dsp/effects.rs`) — кожен по 20–40 рядків: фільтри, перевантаження через `tanh`,
  біткрашер, луна на кільцевому буфері, реверберація Freeverb.
- **Звук** (`src/audio.rs`) — бібліотека `cpal` (WASAPI на Windows). Між мікрофоном і виходом
  стоїть буфер, а вихід читає з нього з трохи змінною швидкістю, бо в мікрофона і кабеля
  різні «годинники».
- **Вікно** (`src/app.rs`) — бібліотека `egui`.

Затримка: ~16 мс на обробку + ~25 мс буфер + буфери Windows. Якщо звук рветься, буфер сам трохи збільшується.

## Збірка з коду

Потрібен [Rust](https://rustup.rs/).

```
cargo run --release
cargo test
```

Кожен push у `main` збирає `.exe` у GitHub Actions. Щоб зробити реліз — постав тег:

```
git tag v0.2.0
git push --tags
```
